Algorithm: RGB LED Colour Control
using Potentiometer
1. Start the Arduino program.
2. Connect the RGB LED to the Arduino using resistors.
3. Set the Red, Green and Blue pins of the RGB LED as OUTPUT.
4. Connect the potentiometer to the Arduino.
5. Read the value from the potentiometer using Arduino.
6. Divide the potentiometer value into different ranges.
7. According to the range, decide which colour of the RGB LED should glow.
8. Send PWM signals to the RGB LED pins to control the colour.
9. Rotate the potentiometer to change the colour of the RGB LED.
