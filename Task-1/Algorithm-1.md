Algorithm: Print Hello world and seconds
timer in LCD 16x2 I2CStart the Arduino
program.
1. Include the I2C library.
2. Create an LCD object for I2C communication.
3. Set the LCD size to 16 columns and 2 rows.
4. Display the message “Hello World” on the first row of the LCD.
5. Move the cursor to second row.
6. Read the running time of Arduino in milliseconds.
7. Convert milliseconds into seconds.
8. Display the seconds on the LCD as a timer.
9. The Loop runs continuously.
